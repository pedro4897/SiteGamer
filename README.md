## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Backend and API

Start the Spring Boot API from the `lojinha` backend folder:

```powershell
.\mvnw.cmd spring-boot:run
```

The API listens on `http://localhost:8081`. The Angular app uses it for customer registration/login, product listing, and order checkout. After inserting a product with Postman, reload the site to see it in the catalog.

Postman requests use the `Content-Type: application/json` header and these URLs:

| Data | URL |
| --- | --- |
| Customer | `http://localhost:8081/api/cliente` |
| Product | `http://localhost:8081/api/produto` |
| Order | `http://localhost:8081/api/pedido` |

Use `POST` to create a product and `PUT` to update one. For `PUT`, send the full product body, including its existing `codigo`, to `http://localhost:8081/api/produto`. To find the product code first, use `GET http://localhost:8081/api/produtos`.

The site lists the signed-in customer's orders from `GET http://localhost:8081/api/pedidos/cliente/{codigoCliente}`. In Postman, use `GET http://localhost:8081/api/pedidos/cliente/1` (replace `1` with the customer's `codigo`) to list that account's orders. Create orders with `POST http://localhost:8081/api/pedido`; update an existing order with `PUT` at the same URL and include its `codigoPedido` and `codigoCliente` in the JSON body.

Example order update:

```json
{
  "codigoPedido": 12,
  "valorTotal": 50.0,
  "entrega": "Rua atualizada, 123",
  "obs": "Deixar na portaria",
  "dataPedido": "2026-11-22",
  "codigoCliente": 1,
  "itens": [
    {
      "codigoProduto": 3,
      "quantidade": 2,
      "valor": 25.0
    }
  ]
}
```

Example customer body:

```json
{
  "nome": "Nome do cliente",
  "telefone": "11999999999",
  "documento": "12345678900",
  "senha": "Senha123!",
  "logradouro": "Rua e número",
  "email": "cliente@exemplo.com",
  "ativo": 1
}
```

Example product body (the `codigo` is generated by the database):

```json
{
  "nome": "Nome do jogo",
  "descritivo": "Descrição do produto",
  "valor": 50.0,
  "valorPromo": 25.0,
  "quantidade": 10,
  "destaque": 1
}
```

Example order body, including the products and quantities:

```json
{
  "valorTotal": 25.0,
  "entrega": "Rua e número",
  "obs": "",
  "dataPedido": "2026-11-22",
  "codigoCliente": 1,
  "itens": [
    {
      "codigoProduto": 1,
      "quantidade": 1,
      "valor": 25.0
    }
  ]
}
```

The site creates orders for the signed-in customer and sends the current cart as `itens`.
